# LUT 运行时代码精简

精简已有 LUT 控制层、后端和缓存，缩小新增代码与静态状态。功能合同继续覆盖 SD JSON 导入、16 槽、八项微调、强度、触摸预览、确认与取消、持久缓存和 AP/CP 生命周期。维护者已在相机上测试精简后的组合固件，反馈运行正常、未发现问题。

AP 在声音生命周期、回放放大兼容、LUT 触摸与比例菜单图标之后，先应用图片配置文件及 LUT 标题字形修复，再重链接精简模块。CP 在比例任务复制、AWB 和机内 RAW FL2/FL3 备选外观之后删除 BUSY 诊断包装。标题字形同步应用于 68 个语言方向银行。[标题图标方法](../../native/menu-ui-fixes/TITLE-ICONS.md)

## 清理范围

| 范围 | 实现 |
| --- | --- |
| P2 工程诊断 | 删除采样、进程读取、诊断时钟、SD 导出及 worker 调用，保留原生颜色执行桥 `p2_job_exec` |
| 事件记录 | 删除 trace、power observer、入口快照和记录调用，保留来源判断、owner 和生命周期分发 |
| RAM 统计页 | 删除关闭入口后遗留的格式化、统计历史、GUI 字段与处理分支 |
| 上传状态 | 将 896 字节统计结构收敛为 72 字节 `upload_schedule_state`，保存实际调度所需时间戳、sequence 和 active |
| 持久缓存 | 链接 `lut_cache.c` 和 `memory.c`，移除闲置声音缓存及其导出 |
| LUT 触摸 | 将原生行选择消息并入 `p4_gui_dispatch`，清空 `0x904D000` 的 280 字节独立适配器 |
| CP 声音回复 | 清空 `0x11FF00` 的 168 字节诊断包装，将 `0xBA5216` 回复跳转恢复至 `0x11F97C`，更新 `0xBA51EC` 的模块 CRC |

上传 worker 保留原来的 8 次基础 WRITE，满足条件时单轮至多 32 次，按 4 ms 窗口决定继续发送。健康 WRITE 使用 1 ms 请求休眠，其余阶段使用 10 ms。ACK 重发、epoch、取消和恢复判断继续使用功能状态。删除旧统计结构时需保留这些依赖。

持久缓存继续接受已有记录，缺失或校验失败时走原编译路径并补建缓存。触摸使用 `0x020F0001`、type 4、widget 9、scene D9 的绝对行号，0 对应“关”，1–16 对应滤镜槽。预览继续交给原事务队列，OK 保存，MENU 恢复进入页面时的选择。

## 重链接和接线

1. 按源码差异删除诊断调用及清单中的十个编译单元。先构建控制层，再将新的控制层符号写入后端链接脚本。控制层 RX 位于 `0x9000000`，状态位于 `0x8F73000`。
2. 后端保留 `0x9031000` 的 33 项、每项 4 字节固定导出表。重建后端时保留第一预留页中的 AP 程序头表。
3. 将 13 个原生 B/BL 入口重绑至新符号。同步更新 6 个工厂指针及对应 `R_AARCH64_RELATIVE` addend。每个地址及目标均列在布局清单。
4. 重建 LUT 缓存，安装至 `0x9048000`。按新符号重定向两个 `readrecord` 调用和一个 `verify_written_record` 调用，清零旧模块尾部。
5. 清除独立触摸适配器。更新 LOAD 的有效长度，后端 LOAD 延伸至 `0x904C110`，容纳现有声音恢复、编号复用和回放辅助模块。
6. CP 按上述三处范围恢复声音回复。CRC 覆盖 `0x11E000..0x120000`，值为 `zlib.crc32(bytes) ^ 0xFFFFFFFF`，以 little-endian u32 写回 `0xBA51EC`。
7. 在本地组装流程中回写 AP、CP，重算对应分区校验与容器签名。源文件差异、模块身份、完整写入范围及重绑定表用于核对结果。

AP 文件偏移通过 `PT_LOAD` 计算，CP 文件偏移为 VA 减 `0x108000`。原生入口与工厂 addend 必须使用同一次链接结果。[精确布局](../../native/custom-lut/runtime-cleanup/layout.json)

## 缩减量

| 统计对象 | 原大小 | 精简后 |
| --- | ---: | ---: |
| 控制层 RX | 61,424 B | 42,228 B |
| 后端 RX，含 ABI 预留页 | 77,436 B | 75,732 B |
| 缓存 RX | 3,551 B | 1,694 B |
| 独立触摸适配器 | 280 B | 0 B |
| CP BUSY 包装 | 168 B | 0 B |
| 控制层静态状态 | 53,128 B | 31,520 B |
| GUI 上下文 | 12,696 B | 12,320 B |

RX 与常量合计减少 23,205 字节，控制层静态状态减少 21,608 字节。固定地址预留和 64 KiB 对齐继续占用空间，AP 与容器长度由现有布局决定。机身可用内存和执行速度收益尚待测量。

## 验证范围

已核对原生入口、工厂重定位、模块重定位、最终 AP/CP 身份及写入范围。机器码回放覆盖两种加载地址的电源分发、16 槽选择、取消恢复、九项编辑、旧缓存迁移、缓存损坏回退、完整 AP/CP 上传、异常时钟和无卡恢复。文件系统、调度、时钟及渲染外部服务使用模型。

维护者的实机反馈为整体运行正常。此前关机黑屏及 MF 放大退出异常的偶发现象尚缺可重现步骤与根因证据，长期稳定性结论仍需后续使用观察。
