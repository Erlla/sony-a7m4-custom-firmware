# LUT 内部界面的英文资源

[English](UI-LANGUAGES.en.md) · [LUT 方法](README.md) · [源码与精确布局](../../native/custom-lut/ui-languages/README.md)

为 [Issue #49](https://github.com/Erlla/sony-a7m4-custom-firmware/issues/49) 涉及的 LUT 内部界面补齐 50 条文案：选卡、文件选择、删除与清空确认、九项调节、空槽、关闭、导入状态和错误提示。简体中文保留，繁体中文提供对应翻译，其余 32 种语言使用英文。用户 LUT 名称、文件名、百分比和页码保持原样。

## 资源位置

新增 ID 为 `0x0204E85E`～`0x0204E88F`，位于 34 个 `share/app/string_<language>.uxc` 共用语言库（bank `0x27`），横竖屏共用。每库索引从 2142 项扩至 2192 项，原索引值和记录内容保持，记录区随索引扩展整体后移。共用库避免在接近 16 位偏移上限的部分竖屏库继续追加记录。

自定义快门声和对焦声使用横竖屏库的 bank `0x05`。两者和 LUT 都由原 AP 语言表选择变体，并经过原 `libObj` 数据库、XDB 路由和 UXC 查找；无需增加另一套语言设置或修改语言切换器。LUT 资源 ID 独立，不覆盖声音文案。

## 显示接线

`lut_ui_text.c` 只接收产品自身的标签，将其转换为原生文字 ID，写入控件参数 `+0x30`，清空 `+0x58` 起的旧格式化参数，再设置 `+0x2C` 激活标志。内联字节表不含绝对指针，无新增可写状态。

两个派生显示函数 `lut_localized_render_overlay` 和 `lut_localized_stock_bind` 复用原 GUI 状态与指针。用户名称继续走原动态文本绑定；即使名称恰好是“取消”或“强度”，也不翻译。关闭、空槽和无效名称等产品占位符才走文字资源。

匹配当前精简布局时，新增只读执行代码位于 AP 虚拟地址 `0x0904D000`，长度 11,248 字节，终点 `0x0904FBF0`。原 `lut_stock_bind` (`0x09004948`) 和 `p4_gui_render_overlay` (`0x0903F664`) 跳转到新函数，并扩展既有 RX 段长度。共享 GUI 指针仍为 `0x09050098`。完整输入、输出、入口和文件偏移差异见 [reference.json](../../native/custom-lut/ui-languages/reference.json)。

该地址在早期触摸组件布局中曾有其他用途；仅适用于清单固定的精简后基线，不能对旧布局直接重放。本次保留已有触摸、快扫、翻页、导入事务和颜色处理代码。

## 组合

AP 与 34 个语言库必须一起集成。资源生成器从本地持有的匹配语言库生成新库，并检查完整输入／输出摘要及旧记录保持；命令见[源码说明](../../native/custom-lut/ui-languages/README.md)。完整 AP 构建还需要匹配的 LUT 基线头文件和 ABI，本目录不是从官方固件一键构建的工具。

`reference.json` 同时记录与最新快捷键、声音实际注册菜单修复及 HEIF 读取修复组合后的 AP/MPR 身份。英文显示层的字节在组合后保持，CP 和更新器未改。其他独立方法继续使用自己的输入限制；不要用旧整份 AP 或 MPR 覆盖组合结果。

## 验证边界

合并后的 AP 已执行原生语言选择、bank 切换和文字查询，覆盖 34 种语言、横竖屏和两档加载偏移，并对照声音资源。显示回放覆盖选卡、文件页、删除确认、九项调节、状态与名称保持。文件读取、内存服务和显示设备查询使用明确夹具。

尚未进行新增英文界面的机身验收，字体栅格化、长提示截断和换行仍需实机确认。此前快捷键或 HEIF 的实机结果不等于本次英文组合的验收。
