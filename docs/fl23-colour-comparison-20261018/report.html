二、FL2 / FL3具体配方差异与上游v2.0核对

参数层面的区别：FX2 原厂与当前配方的照片色度和Gamma相同，主要区别是三光源矩阵；原 A7C II 项目 0.1.0与它们同时存在色度、矩阵和照片槽6 Gamma差异。上游v2.0的FL2/FL3配方未改变。 本节为新增的静态配方核验；此前12对照片的测量数值与排序保持不变，没有新增v2.0实拍组。

本次读取三个测试方案各自实际交付包的已验证明文，核验完整SHA-256；逐一提取全部32份地区BK4模板，确认照片配方一致，并核对CP实际使用的静态色度与Gamma。这里的“FX2 原厂”表示将FX2原生参数用于本次M4方案，不是拿FX2机身拍摄，也没有把M4的白平衡/传感器校准更换为FX2。

六、测量方法与复核

  1. 输入固定：为原JPG、原始ARW和处理ARW记录SHA-256及大小；只用24张JPG计算直方图和像素差，分析前后核对输入未变化。原始照片均未改写或重新显影；本次公开仅包含报告派生图，不上传原始照片。
  2. 原尺寸直方图：每张图用全部32,741,376个像素，对R/G/B及Y′计算256档计数、归一化概率。交集Σmin(p,q)，总变差0.5Σ|p−q|；W1为离散CDF差的绝对面积。另保存BC、JS和16档粗分箱结果，不以单一指标代替全部判断。
  3. 固定色块测区：在查看数值差异之前，从机内图选择共同6×4网格；采样每格中心30%宽、30%高，避开边框与明显边缘。三种方案与每对后期图共用同一规则，不按误差大小挑选区域。主结果先将原尺寸sRGB像素转换为Lab D65，逐块求平均Lab，计算两均色之间ΔE00，再等权汇总24块。色卡没有被当作已校准的准确度标准。
  4. 色差算法验证：CIEDE2000取kL=kC=kH=1；通过Sharma、Wu、Dalal公开的34组参考数据，最大绝对误差 0.00004950。另有恒等、对称性、sRGB红/中灰以及直方图端点测试。
  5. 不同实现复核：使用Pillow原生histogram和ImageChops差图，分别重算24图RGB计数及12对MAE/PSNR，与主NumPy分块实现一致。这是同任务另一种计算实现，不声称独立人员审查。
  6. 缩放与测区敏感性：主色块结果使用原图。原图与1752×1168缩图的24块平均色差最大差为 0.002321。下面将中心区域改为20%/30%/40%进行补充检查；这些敏感性值在同一缩图网格计算，FL2/FL3顺序均不变。

七、结论与后续用途

  • FL：三组24块平均色差均约1.444，13/8/4号块共同偏差突出；不排优劣，也不将其平均值作为可扣除的固定误差。
  • 以匹配本次Edit参考为目标，本批FL2/FL3均优先保留当前配方；FX2 原厂居中；原 A7C II 项目 0.1.0在本次M4测试的偏差较大。该判断同时得到直方图交集、W1和原尺寸色块均色差支持。
  • 当前配方的FL3已较接近参考；FL2黄/橙色块仍需要单独关注。下一步可围绕7、12、16号块定位差异，不应仅凭均值宣布全部颜色一致。
  • 这份结果不能独立证明A7C II原项目本身存在错误，也不能区分矩阵、色度、Gamma、RAW参考和机内/软件渲染各自贡献。涉及参数修正时，应先核对相关输入与实际加载状态，再做一次只改变一个变量的对照。
  • 若要推广到其他光源，需在不同色温/光谱下重复同样的配对测试并做重复拍摄；本报告不触发新的相机操作或固件修改。
