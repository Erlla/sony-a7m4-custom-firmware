# 三种配方的机内直出与 Edit 后期色彩差异报告

2026-10-18 · Sony A7M4 · 固定曝光、白平衡和镜头的新批次测试

**本批次的结论：FL2、FL3中，“当前配方”与用户提供的对应Edit后期图最接近，“FX2 原厂”其次，“原 A7C II 项目 0.1.0”差异最大。** 全图直方图与原尺寸色块均色两类指标给出相同顺序，中心测区尺寸变化也未改变该顺序。当前配方的FL3更接近后期参考；FL2仍有黄、橙色块残差，不能称为完全相同。

本报告只分析这次固定条件新批次的24张JPG、12对照片，未混用此前已暂停批次。**“更接近”指直出与本次Edit参考的一致程度，不是相对真实场景的色彩准确率，也不是所有光源的通用结论。** 全部机内图均来自ILCE-7M4；“FX2 原厂”是按用户要求使用的参数方案名称。

### 当前配方的剩余差异

当前配方FL2的24块均色ΔE00平均值为 **1.233**，但最差的几个色块是 **12号块 5.016、16号块 4.212、7号块 4.097**。这些区域在色卡中为黄/橙色区域；本对比中，Edit相对直出更亮，b*更低，即更少黄。平均值较低不表示这些局部已经吻合。

当前配方FL3的24块平均值为 **0.678**，最差色块为 **1.454**。在本次条件下，它比另外两种方案的FL3更接近Edit参考。

原 A7C II 项目 0.1.0的FL2、FL3色块均色ΔE00分别为 **4.336 / 4.070**，18个彩色块与6个灰阶块都有差异。其Edit参考相对机内图的平均L*分别高约 **3.82 / 3.41**，同时伴随不同颜色区域的a*/b*变化，不能仅用统一曝光偏移概括。

![FL2/FL3各色块误差](assets/FL23_patch_heatmaps.png)

图中编号从左到右、从上到下为1—24，第4行是灰阶区域。六个面板共用0—12的色差刻度。数值为**原尺寸JPEG的色块均色差**，不是与色卡厂家标准Lab的偏差。

## 五、测量方法与复核

1. **输入固定**：为原JPG、原始ARW和处理ARW记录SHA-256及大小；只用24张JPG计算直方图和像素差，分析前后核对输入未变化。原始照片均未改写或重新显影；本次公开仅包含报告派生图，不上传原始照片。
2. **原尺寸直方图**：每张图用全部32,741,376个像素，对R/G/B及Y′计算256档计数、归一化概率。交集`Σmin(p,q)`，总变差`0.5Σ|p−q|`；W1为离散CDF差的绝对面积。另保存BC、JS和16档粗分箱结果，不以单一指标代替全部判断。
3. **固定色块测区**：在查看数值差异之前，从机内图选择共同6×4网格；采样每格中心30%宽、30%高，避开边框与明显边缘。三种方案与每对后期图共用同一规则，不按误差大小挑选区域。主结果先将原尺寸sRGB像素转换为Lab D65，逐块求平均Lab，计算两均色之间ΔE00，再等权汇总24块。色卡没有被当作已校准的准确度标准。
4. **色差算法验证**：CIEDE2000取kL=kC=kH=1；通过[Sharma、Wu、Dalal公开的34组参考数据](https://hajim.rochester.edu/ece/sites/gsharma/ciede2000/)，最大绝对误差 **0.00004950**。另有恒等、对称性、sRGB红/中灰以及直方图端点测试。
5. **不同实现复核**：使用Pillow原生histogram和ImageChops差图，分别重算24图RGB计数及12对MAE/PSNR，与主NumPy分块实现一致。这是同任务另一种计算实现，不声称独立人员审查。
6. **缩放与测区敏感性**：主色块结果使用原图。原图与1752×1168缩图的24块平均色差最大差为 **0.002321**。下面将中心区域改为20%/30%/40%进行补充检查；这些敏感性值在同一缩图网格计算，FL2/FL3顺序均不变。

| FX2 原厂 | FL2 | 1.560 | 1.566 | 1.566 |
| FX2 原厂 | FL3 | 0.953 | 0.949 | 0.950 |
| 当前配方 | FL2 | 1.236 | 1.233 | 1.230 |
| 当前配方 | FL3 | 0.678 | 0.679 | 0.676 |
| 原 A7C II 项目 0.1.0 | FL2 | 4.338 | 4.337 | 4.334 |

24个色块属于同一次拍摄，不是24次独立固件实验；测区敏感性也不是物理重拍重复性。当前结果不提供跨光源通用排名、统计显著性或真实色彩准确度判断。

## 六、结论与后续用途

- 以**匹配本次Edit参考**为目标，本批FL2/FL3均优先保留**当前配方**；FX2 原厂居中；原 A7C II 项目 0.1.0在本次M4测试的偏差较大。该判断同时得到直方图交集、W1和原尺寸色块均色差支持。
- 当前配方的**FL3已较接近参考**；**FL2黄/橙色块仍需要单独关注**。下一步可围绕7、12、16号块定位差异，不应仅凭均值宣布全部颜色一致。
- 这份结果不能独立证明A7C II原项目本身存在错误，也不能区分矩阵、色度、Gamma、RAW参考和机内/软件渲染各自贡献。涉及参数修正时，应先核对相关输入与实际加载状态，再做一次只改变一个变量的对照。
- 若要推广到其他光源，需在不同色温/光谱下重复同样的配对测试并做重复拍摄；本报告不触发新的相机操作或固件修改。
