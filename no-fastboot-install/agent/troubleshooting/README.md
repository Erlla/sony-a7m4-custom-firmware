# M4 USB 补丁：历史问题与排障索引

更新：2026-11-11。收录 28 类实际遇到的问题，供 Agent 按需查阅。这里公开当前结论、排查依据及处理边界，不上传原始日志、p1、机身标识、私人路径或整段研究过程。

## Agent 怎么用

1. 先在原目录查询原 `job`，取得构建标识、失败阶段、诊断码、写入/清理状态和当前待办。
2. 读取 [index.json](index.json)，用准确报错、诊断码和阶段找候选；只读取匹配的分类文档。无需每次下载全部历史资料。
3. 核对条目的“本轮应核对”。关键词命中只是线索；例如 `StageBind` 可能是证书、缺文件、待重启，不能直接定因。多个条目命中时结合当前证据缩小范围。
4. 原因已经证实就说明依据并通过正式入口处理；证据不足就明确尚未确定、继续收集具体缺项。当前程序待办决定允许的命令，旧文档不能越过它。
5. 系统授权、Windows 重启、相机重启、USB 拔插分开提示并等待真实回复。处理后查同一任务，不能因错误相同而重复写入。
6. 索引不可访问时可以继续查询已有任务和当前正式恢复待办；说明未能查历史记录，不编造旧案例。未匹配的故障保留为新问题，不强行套用最近的条目。

`cause_status` 说明历史证据范围；`match_is_diagnosis=false` 明确禁止把搜索结果当成已证实诊断。文档更新后仍应以当前任务的真实结果为准。

## 版本不要混淆

| 系列 | 说明 |
|---|---|
| 历史桌面端 1.00／1.0.1／1.02 | 条目中的历史版本；不是独立 Agent 版本 |
| 旧实验 Agent `1.02-agent-20261110-r1`～`r6` | 沿用桌面编号的开发构建；r5 完成本机实机演练，r6 为离线提速验证 |
| 桌面 / Agent **1.03** | 共用源码；当前 Agent 构建 `1.03-agent-20261111-r1`，修复连接停止后的原任务菜单续接，本构建尚未做新的干净 Windows／相机验收 |

1.03 已作为 [GitHub 正式版附件](https://github.com/Erlla/sony-a7m4-custom-firmware/releases/tag/A7M4-Agent-ToolKit-V1.03) 提供；[资源清单](../resources.json)已固定当前构建的下载地址、大小和 SHA-256，公开 ZIP 核对与本地交付一致。本构建仍需新的干净 Windows／相机验收。旧实验 `1.02-agent-20261110-r1` 有本页 USB-022～024 的已知问题，不用于新写入任务；已有任务先在原目录查询、按当前允许的待办恢复，不能复制到新构建继续。后续替换附件时应同步资源清单和验收范围。

## 维护规则

- 每个条目保留匹配线索、历史原因、本轮核对项、处理方式与验证范围；未知根因不写成已修复。
- 新证据推翻旧建议时修改对应条目。早期删除 ProgramData／状态后重试的做法已被保留记录的初始化和恢复流程替代，不再推荐。
- 实际案例、模拟测试、干净电脑验收、实机写入分别描述。新电脑验证不能借用开发机遗留驱动、证书、任务或状态。
- 不把问题库变成现场修补脚本集合：Agent 只运行正式入口，不改补丁、白名单、清单或状态。源码修复与重新构建由维护流程完成。
- 本地保留来源报告及摘要用于追溯；公开内容只保留脱敏结论。后续贡献问题先去除私人日志、设备标识和备份。
