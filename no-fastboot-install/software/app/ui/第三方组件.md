# 第三方组件

运行组件只保留当前工作流需要的部分。各组件继续适用其原有许可，本工具的名称不改变第三方代码或二进制的许可。

| 组件 | 用途 | 来源与许可资料 |
|---|---|---|
| CPython 3.12.14、Tcl/Tk 8.6 | 独立 Python 和窗口运行时 | [CPython](https://github.com/python/cpython/tree/v3.12.14)、`runtime/python/LICENSE.txt`、Tcl/Tk 相邻许可文件 |
| PyUSB、libusb-package、importlib_resources | USB 通信和本地 USB 库定位 | `vendor/usb/` 中的包及 `.dist-info` 元数据／许可证 |
| Sony-PMCA-RE | Senser 认证常量和兼容 SHA-1 实现 | [上游项目](https://github.com/ma1co/Sony-PMCA-RE)、`licenses/Sony-PMCA-RE.txt` |
| Dissect FAT、SquashFS、cstruct、util | 更新环境文件系统解析 | `vendor/python/`、`vendor/squashfs/` 中的对应包、许可证和元数据 |
| pyelftools | ELF 结构与原生任务校验 | [pyelftools](https://github.com/eliben/pyelftools)、相邻 `.dist-info` 许可资料 |
| cryptography、cffi、pycparser | 现有更新器 RSA 公钥格式校验 | `vendor/python/` 中的对应包及许可资料 |
| squashfs-tools-ng 1.3.2 | 重建本次更新器文件系统 | [上游源码](https://github.com/AgentD/squashfs-tools-ng/tree/v1.3.2)、`tools/squashfs/` 和 `licenses/`；可执行工具与库分别适用其原有 GPL/LGPL 等条款 |
| Zig 0.15.2 及其 Clang/LLVM 组件 | 构建每轮独立原生任务 | [Zig](https://github.com/ziglang/zig/tree/0.15.2)、`tools/zig/` 原有头文件版权说明和 `licenses/Zig.txt` |
| WinUSB 绑定文件 | Windows 驱动辅助配置 | `tools/driver/` 保留原始签名字节，文件继续适用其厂商条款；不将其标为本项目原创源码 |

Python 的 `ssl.py` 使用与运行时版本对应的 [CPython 3.12.14 原始文件](https://github.com/python/cpython/blob/v3.12.14/Lib/ssl.py)，没有携带开发机器的 Codex 证书配置。TLS 客户端默认的证书验证与主机名检查保持启用。

本包不包含 Capstone、Unicorn、完整仿真环境、相机库、固件、个人校准或作者私钥。参考方案致谢：[YuuLuo/a7c2-camera-tools](https://github.com/YuuLuo/a7c2-camera-tools)。
