# M4 相机工具 / AI Agent 1.03

通过普通 USB 为 Sony ILCE-7M4 准备更新环境，再由相机从存储卡安装固件。

点击软件底部的 GitHub 项目链接，可使用默认浏览器打开项目主页。

## 使用

1. 完整解压到较短目录，例如 `D:\M4`，不要在压缩包中启动，也不要只复制 EXE。
2. 自行将适用于相机的 `BODYDATA.DAT` 放入**卡槽 1 存储卡根目录**。
3. 使用原厂电池，保持电量充足和稳定供电。相机开机，以 **USB 海量存储模式**连接电脑。
4. 打开 **M4相机工具.exe**，按 Windows 提示确认管理员授权，再勾选准备确认，点击**写入补丁**。取消授权会退出软件。
5. 等待备份、按需补丁、完整回读和菜单准备。中途若提示重新连接 USB，保持相机开机，重新插拔后继续；此时先不要更新。
6. 明确显示**可以拔下 USB 开始更新**后，保持相机开机并拔线，先回拍摄界面，再进入“版本／软件更新”，自行核对目标并执行。
7. 菜单窗口约 10 分钟，应在窗口有效时开始更新。已经开始安装后等待相机完成，不因电脑倒计时结束而断电。
8. 相机完成更新并重启后，检查版本、拍摄、保存和回放，点击**更新已结束**。这一步不要求重新连接电脑。

本工具不附带完整固件，也不读取、检查或复制卡上的安装包。机内更新器和菜单关键代码必须匹配已核对布局；显示版本号不设白名单，不代表任意固件都兼容。

新电脑首次使用时，可能询问是否安装相机 USB 驱动证书（普通连接与服务连接各一张）。它们是 libwdi 自动生成的自签名证书，并非索尼或微软签名；只有选择“是”才安装，选择“否”会停止，不切换驱动。

如果首次初始化中断，重新连接后点击“重新检查并写入补丁”即可继续准备。软件会复用匹配的配置并补齐缺失任务，无需手动删除 Windows 计划任务或 ProgramData 文件夹。

界面提示使用前暂时关闭杀毒软件及 Windows Defender，操作结束后及时恢复防护。该提示不会自动更改电脑的防护设置。若发生威胁检测，请保留威胁名称、文件路径及原始文件用于排查；此前检测样本尚未取得微软复核结论。

## 恢复连接与记录

补丁与菜单准备期间复用本工具已核对的 WinUSB 驱动，中间不卸载驱动，也不等待电脑盘符。p1 完整备份、写后独立完整回读、机身身份与菜单就绪检查保留。再次使用时，可直接复用仍可用的驱动。

需要通过电脑传输照片，或相机显示“请检查所连接的设备”时，点击**恢复普通 USB**，按提示重新连接。它是独立操作，不是固件操作完成的前提，也不会再次写入补丁。相机仍在更新时请先等待结束。

USB 身份失败可能发生在备份前或菜单准备前，请按日志的实际阶段处理。若 p1 已完成而菜单会话尚未开始，点击“检查连接并继续菜单”，核对连接后只继续菜单准备，不再写入 p1；也可选择恢复普通 USB。只有明确显示“可以拔下 USB 开始更新”后才进入相机更新菜单。

如果提示**请重启电脑**，请保存工作并重启 Windows，再打开工具继续。此提示对应 Windows 驱动变更需要重启生效，重新打开软件或插拔相机 USB 不能代替。工具会核对重启后的驱动状态，保留原始记录；不会自动重启电脑。

如果日志显示**当前相机固件非6.02版本**，说明相机里的固件库不符合当前工具支持的内容，补丁尚未写入。可点击**恢复普通 USB**恢复连接；重复写入不会解决库不兼容。读取任务开始前的连接失败也可使用该恢复按钮，无需写入材料。

只读预检失败时，工具会先等待并核对相机端清理记录。确认清理完成、更新菜单尚未启动后，会正常结束服务会话并允许**恢复普通 USB**。若清理结果未确认，工具保留原始错误和日志，不会自动重发读取或写入。

日志、备份和当前任务位于 `state/`；“查看日志”和“打开运行记录”可直接打开对应位置。

发生错误时，界面会显示停止阶段、已知原因和下一步操作，日志保留原始错误及后续收尾错误。若显示“更新菜单尚未交接”，请不要安装：正常关闭相机，等存取灯熄灭后开机，再点击“相机已重启，恢复 USB”。若相机已经开始更新，请等待更新结束。

等待时间较长时会显示当前步骤的等待秒数。软件不会因等待超时自动重发写入。请保留首次错误的运行记录；具体原因未取得时，不会把通信错误直接解释成固件损坏。

每次重新打开软件，都回到初始“写入补丁”界面，可直接使用“恢复普通 USB”。旧备份和日志保留；若上次 USB 恢复仍在运行或结果尚未确认，软件会继续确认原任务，不会重复恢复。新补丁操作重新读取相机，不复用上次的写入材料。相机正在更新时，应先等待更新完成。

## 恢复官方固件

自定义固件内的更新器须支持再次更新，且版本顺序符合官方要求；满足条件后按索尼官方流程安装官方原包即可，无需再次打补丁。完整 p1 备份不等于全部 eMMC 或 CP NOR 备份。

## 分发与验证

版本为 **1.03**。此包不含完整 DAT、相机固件库、其他机身的绑定、备份或历史运行任务。请使用原始 ZIP 分发，不要重新打包使用后的软件目录。

此前版本的安装流程已获实测通过反馈；其他电脑和相机仍须按实际连接及代码兼容性检查结果操作。

免 Fastboot 安装方案参考 [YuuLuo/a7c2-camera-tools](https://github.com/YuuLuo/a7c2-camera-tools)。Windows 驱动复用与独立恢复的设计参考 [QAQLeonard/a7c2-tools](https://github.com/QAQLeonard/a7c2-tools)，感谢其公开研究与实现思路。第三方运行组件及许可见 [第三方组件](https://github.com/Erlla/sony-a7m4-custom-firmware/blob/main/no-fastboot-install/software/THIRD_PARTY.md)。

“恢复普通 USB”可在启动后直接点击，无需先运行补丁或勾选准备确认。仅当前后台任务运行时按钮暂不可用。无本机任务记录时，只恢复已识别的 M4 Windows 驱动，不进入相机服务会话、不读写 p1；首次恢复可能需要管理员授权。按提示保持相机开机、重新插拔 USB 后再次点击确认。已有未决写入仍沿原任务核对，不能用此入口跳过。

若补丁已完成、仅在电脑端准备菜单时失败，界面会提供“继续准备更新菜单”。请从原目录继续，保留 state，不要重新写入补丁。菜单一旦形成计划或开始执行，仍按原任务记录处理，不自动重复启动。

Agent 1.03：独立 Agent 1.00/1.01 的已停止菜单任务，可在保留 state 的原目录升级后用 --agent resume <原job> 重新生成确认。按当前待办选择继续菜单或恢复普通 USB。只有菜单未开始且完整证据匹配时允许续接；不重新派发 p1 writer。

1.03 将通信等待收敛到单次后台轮询，并保留实际阶段和底层 USB 错误码。本轮离线回归不替代新的相机或干净 Windows 实机验收。
