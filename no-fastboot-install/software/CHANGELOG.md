# M4 桌面与 Agent 1.03

- 桌面端与 Agent 从同一套源码构建，减少两个入口修复不同步。
- 普通 USB 等待改为一个后台进程内轮询，结束后只生成一个快照；不要求盘符恢复才能继续菜单。
- p1 已完成而菜单会话未开始时，可检查连接并只继续菜单，或独立恢复 USB；不重新派发 p1 写入。
- 错误摘要保留真实阶段、设备/LANGID/身份字符串差异、errno 与 libusb 错误码，不将传输错误直接推断为固件损坏。
- 独立 Agent 1.00/1.01 的限定已停止任务可在原目录保留 state 后升级并生成新确认；活动或结果未知的任务不重发。
- 下载辅助脚本保留 UTF-8 BOM，兼容 Windows PowerShell 5.1 的中文解析。

验证：211 项源码用例、16 组包级检查、8 项惰性下载检查通过，21 个 PowerShell 文件在 5.1 解析通过。包级检查包含原生启动链、首次配置替身、驱动复用/恢复、stock/user 菜单路径及桌面实际控件路由。开发回归使用替身，不会出现在用户每次补丁操作中。

本轮未进行新的全新 Windows 或真实相机安装验收；完整备份和独立回读保持，不能据此承诺所有 USB 硬件问题均已解决。详细范围见 [VALIDATION-1.03.json](VALIDATION-1.03.json)。

源码现在统一维护在 no-fastboot-install/software/；旧 agent/source/ 仅保留迁移入口。原提示词链接保持不变。A7C2 参考项目的当前提交与此前研究相同，本次补齐主机轮询、续接和诊断，不照搬机型相关协议。
