# M4 相机工具 1.00

软件面向手动准备安装包的用户：放包到卡槽 1 → USB 连接电脑 → **写入补丁** → 按提示拔线 → 在相机执行更新。使用步骤见 [README](README.md)。

## 当前功能

| 入口 | 用途 |
|---|---|
| 写入补丁 | 完整备份当前 p1，检查实际内容，按需写入并独立全读，随后准备限时更新菜单 |
| 恢复普通 USB | 启动后可直接检查并恢复 Windows 普通连接；已有未决任务沿原证据流程核对，不重新写补丁、不启动菜单 |
| 查看日志／打开运行记录 | 查看本机产生的备份及记录 |

软件没有“相机”“固件文件”侧栏，也不提供恢复官方的操作按钮。不读取、查找、哈希校验或复制 SD 卡安装包，不因更换目标包要求更换软件。

相机显示版本号不作为白名单；实际关键代码或布局不兼容时停止。补丁正确时无需重复写入，但仍需读取验证。常规操作保留完整性校验、完整备份和写后独立完整回读，不执行完整 ARM64 仿真或模拟断连、短写、回滚失败测试。

## 首次配置与连接恢复

首次运行需要正常确认 Windows 管理员 UAC，用于本机驱动辅助配置。软件不自动确认 UAC。每份运行目录绑定本机用户和相机；新用户应从干净分发包开始，不能使用别人的绑定、分区备份或历史任务。

提示重新连接 USB 时，保持相机开机、重新插拔线即可，随后由软件确认连接。恢复普通 USB 仅处理通信和驱动状态，不恢复官方固件。

电脑端创建初始记录失败时，软件先核对是否尚未进入设备步骤，再结案本地失败并允许独立恢复连接，不要求提供尚未生成的写入材料。状态文件短暂占用仅重试本地 JSON 发布，不重复提交设备操作。

写入结果不明时先核对原生结果及备份，必要时独立完整回读 p1，确认后才能恢复驱动。回读不一致或驱动任务结果不明仍停止，不能删状态文件强行再写。

## 再次打开软件

安全结束的任务回到初始“写入补丁”界面。补丁及普通 USB 已验证且菜单尚未启动的任务，也可在再次点击时归档并开始新一轮。备份和日志保留。

写入结果不明、驱动恢复未完成、菜单窗口已启动等情况继续显示原任务状态；关闭窗口不清除这些保护。

## 恢复官方 6.02

自定义目标包内的更新器须具有正确的再次更新逻辑，并满足官方升级版本顺序；本机已从这样的自定义固件按正常菜单安装官方 6.02，无需再运行补丁工具。应在相机上检查版本、拍摄、保存和回放；工具本身不判定最终 DAT 是否安装成功。

## 分发状态

版本保持 **1.00**。[软件源码与构建说明](software/README.md) 提供当前界面、流程和原生任务实现。第三方运行组件独立准备，本次同步不附 EXE、运行时、固件库或研究工作目录，也不创建二进制 Release。

纯本地菜单准备失败时，完整补丁与回读证据仍保留，界面提供“继续准备更新菜单”；已经形成菜单计划或开始执行时不自动重发。重新开始补丁与继续菜单是不同操作。
