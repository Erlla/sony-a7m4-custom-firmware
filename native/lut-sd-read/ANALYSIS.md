# Custom LUT 的 SD 卡快扫

导入列表先按文件名枚举 JSON 候选。选中并确认后，相机重新读取该文件，检查 128 KiB 上限并解析 JSON。无效或超大的文件可能显示在列表中，确认导入时会报错。

快扫将逐文件解析改为登记文件名，并清零扫描记录的元数据。确认路径保留实际读入和解析，移除原先对扫描记录中大小和元数据的比较。三个改写位点见 `patches/fast_scan.json` 和 `patches/import_relax.json`。

SD 导入列表用左右键切页，上下键在当前页选择文件。每批读取 16 个候选，导入目录最多 256 个目录项，机内有 16 个自定义槽位。导入目录为 `PRIVATE/M4ROOT/GENERAL/LUT/`。
